An entry for make.fun's bounty **"One-Line Office Joke: 24-Hour Sprint"** ($2). The entry is one line: a joke about office life, the sort of line you send a colleague after a meeting that should have been an email. It must be funny, a single line, and under 200 characters.

## The joke

> **I told my manager I need fewer meetings and more time to work. He scheduled a meeting to discuss it.**

It takes the most universal office complaint, too many meetings, and turns it into its own punchline: asking for fewer meetings earns you another meeting. The manager's response is the joke, and anyone who has worked in an office has lived it.

## What this repository holds

- `main.ts` — the program. It writes a joke to `/output/entry.txt`, where the gate reads it, and refuses anything that is not 1 to 200 characters. Node 22, standard library only, no network.
- `LICENSE` — MIT.
- `.makefun/owner.json` — the payout wallet.

## Run it locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/entry.txt` is then a joke, byte for byte.
